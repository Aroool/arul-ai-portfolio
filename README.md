# Arulprashath — AI Portfolio

Personal portfolio for Arulprashath Rajarajan, a Computer Science Master's student at Clark University and software/AI engineer.

Built with **Next.js**, **Framer Motion**, and **Tailwind CSS**. Includes an AI assistant powered by GPT-4o mini that can answer questions about Arul's background, projects, and experience.

## Features

- AI chat assistant (ask anything about Arul)
- Projects showcase with GitHub contribution heatmap
- Open source contributions section
- Contact page

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion/)
- [AI SDK](https://sdk.vercel.ai) + OpenAI GPT-4o mini

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Requires an `OPENAI_API_KEY` environment variable.
